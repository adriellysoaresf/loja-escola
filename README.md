## ✦ Sobre o projeto

O **Herbário Impossível** é uma loja fictícia de flores e plantas extraordinárias.

O projeto apresenta uma vitrine com filtros, páginas dinâmicas de produtos, seleção de quantidade, checkout simulado e confirmação do pedido.

## ✦ Funcionalidades

- Pesquisa e filtragem de produtos
- Página dinâmica de detalhes
- Seleção de quantidade
- Consulta de endereço pelo CEP
- Checkout e confirmação de compra
